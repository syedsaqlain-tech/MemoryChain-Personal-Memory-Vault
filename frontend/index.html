Store photos, documents and memories safely.

🛡️ Verify Files

* HTML * CSS * JavaScript * Python (Flask) * MySQL * Solidity * Hardhat * Ganache * Web3.py

Detects whether uploaded files have been modified by comparing SHA-256 hashes.
